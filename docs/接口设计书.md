# 接口设计书

## 1. 通用约定

- 基础地址：`http://localhost:8080`，业务接口前缀 `/api`。
- 数据交换：JSON（文件上传使用 `multipart/form-data`）。
- 统一返回体：

```json
{ "code": 200, "message": "success", "data": {} }
```

- 分页结构 `PageResult`：`{ records, total, page, size, totalPages }`。
- 认证方式：登录后返回 JWT，后续请求带请求头 `Authorization: Bearer <token>`。
- 时间字段为 `yyyy-MM-ddTHH:mm:ss` 字符串。
- 响应头返回 `X-Request-Id` 与 `X-Response-Time` 便于链路排查。

### 错误码

| code | 含义 |
| --- | --- |
| 200 | 成功 |
| 400 | 参数或业务校验失败 |
| 401 | 未登录或登录已过期 |
| 403 | 越权（非本人且非管理员） |
| 404 | 资源不存在或已删除 |
| 409 | 冲突（如用户名已存在） |
| 429 | 请求过于频繁（登录连续失败限流） |
| 500 | 服务器内部错误 |

## 3. 接口详情

### 3.1 认证

**POST /api/auth/register**　请求体：

```json
{ "username": "alice", "password": "123456", "nickname": "爱丽丝" }
```

响应：`data` = `AuthResponse` = `{ token, tokenType, expiresAt, user }`。

**POST /api/auth/login**　请求体：`{ "username": "admin", "password": "admin123" }`，响应同上。连续失败 5 次返回 429。

**GET /api/auth/me**　响应 `data` = `UserVO` = `{ id, username, nickname, role }`。

**POST /api/auth/logout**　JWT 无状态，服务端直接成功，客户端删除本地 token。

### 3.2 视频

**POST /api/video/upload**　`multipart/form-data`：

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| file | 是 | 视频，mp4/webm/mkv/mov/avi |
| cover | 否 | 封面，JPG/PNG/WebP，≤5MB |
| title | 否 | 留空用原文件名 |
| description | 否 | ≤500 字符 |
| category | 否 | 默认“默认” |
| tags | 否 | 逗号分隔 |
| duration | 否 | 前端解析时长，后端解析失败时兜底 |

响应 `data` = `VideoVO`。

**POST /api/video/{id}/cover**　`multipart/form-data`：`cover` 必填；非本人且非管理员返回 403。

**GET /api/video/page**　查询参数：

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| page | 1 | 页码 |
| size | 8 | 每页条数（最大 100） |
| keyword | 空 | 标题/简介模糊匹配 |
| category | 全部 | 分类筛选 |
| sortBy | create_time | create_time / play_count / like_count / size |
| order | desc | asc / desc |

响应 `data` = `PageResult<VideoVO>`。

**GET /api/video/{id}**　响应 `data` = `VideoVO`；不存在返回 404。

**DELETE /api/video/{id}**　逻辑删除并清理磁盘文件；非本人且非管理员返回 403。

**POST /api/video/{id}/play**　播放量 +1，无请求体。

**POST /api/video/{id}/like**　切换点赞，响应 `data` = `LikeResult` = `{ liked, likeCount }`。

**GET /api/video/categories**　响应 `data` = 分类字符串数组，含“全部”。

**GET /api/video/hot?limit=5**　响应 `data` = `VideoVO` 数组，按播放量倒序。

**GET /api/video/cover/{fileName}**　返回图片，带浏览器缓存头。

**GET /api/video/stream/{fileName}**　视频流式播放，支持 `Range` 请求头。

### 3.3 信息

**GET /api/v1/info**　响应 `data` = `{ "name": "video-backend", "version": "2.0.0" }`。

## 4. 数据模型

`VideoVO` 字段：`id, title, description, url, coverUrl, sizeText, duration, durationText, format, category, tags[], playCount, likeCount, ownerId, uploader, createTime`。

`LikeResult` 字段：`liked`（切换后是否已点赞）、`likeCount`（切换后总数）。

## 5. 视频流与断点续播（HTTP Range）

`GET /api/video/stream/{fileName}` 实现要点：

- 无 `Range`：返回前 1MB，状态 200。
- 有 `Range: bytes=start-end`：返回 `206 Partial Content`，并带 `Accept-Ranges: bytes` 与 `Content-Range`。
- 范围非法：返回 `416 Requested Range Not Satisfiable`。

```text
请求：GET /api/video/stream/xxx.webm
      Range: bytes=0-1023
响应：206 Partial Content
      Accept-Ranges: bytes
      Content-Range: bytes 0-1023/<总长度>
```

浏览器据此可拖动进度条并实现断点续播（前端另用 `localStorage` 记忆播放位置）。
