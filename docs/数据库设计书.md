# 数据库设计书

## 1. 设计概述

数据库名 `video_db`，字符集 `utf8mb4`、排序规则 `utf8mb4_unicode_ci`，包含 3 张表：

| 表名 | 说明 |
| --- | --- |
| `app_user` | 系统用户，保存 BCrypt 密码摘要、昵称、角色、状态 |
| `video` | 视频信息，含归属用户 `owner_id`、封面字段、播放量/点赞数、逻辑删除标记 |
| `video_like` | 点赞记录，`user_id + video_id` 唯一索引保证同一用户只赞一次 |

## 2. 设计约定

- 主键统一为 `BIGINT AUTO_INCREMENT`。
- 时间字段 `create_time` / `update_time` 使用 `DATETIME`，默认 `CURRENT_TIMESTAMP`，`update_time` 自动更新。
- 布尔语义用 `TINYINT`（`status`：0 禁用 / 1 正常；`deleted`：0 正常 / 1 删除）。
- 不使用物理删除视频，改用 `deleted` 逻辑删除，保证列表与检索的数据一致性。
- 同一用户对同一视频的点赞通过唯一索引去重。

## 3. E-R 关系

- `app_user` 1 —— N `video`：一个用户可上传多个视频（`video.owner_id → app_user.id`）。
- `app_user` N —— N `video`：点赞关系，用中间表 `video_like` 表示，`video_like.user_id → app_user.id`、`video_like.video_id → video.id`。

```text
app_user (1) ──< (N) video
app_user (1) ──< (N) video_like (N) >── (1) video
```

## 4. 表结构明细

### 4.1 app_user 系统用户表

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | BIGINT | PK, AUTO_INCREMENT | 用户主键 |
| username | VARCHAR(32) | NOT NULL, UNIQUE | 登录名 |
| password_hash | VARCHAR(100) | NOT NULL | BCrypt 密码摘要 |
| nickname | VARCHAR(50) | NOT NULL | 显示昵称 |
| role | VARCHAR(20) | NOT NULL, DEFAULT 'USER' | USER / ADMIN |
| status | TINYINT | NOT NULL, DEFAULT 1 | 0 禁用 / 1 正常 |
| last_login_time | DATETIME | NULL | 最近登录时间 |
| create_time | DATETIME | NOT NULL, DEFAULT now | 创建时间 |
| update_time | DATETIME | NOT NULL, 自动更新 | 更新时间 |

### 4.2 video 视频信息表

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | BIGINT | PK, AUTO_INCREMENT | 主键 |
| title | VARCHAR(200) | NOT NULL | 标题 |
| description | VARCHAR(500) | NULL | 简介 |
| file_name | VARCHAR(255) | NOT NULL | 磁盘存储文件名（UUID） |
| original_name | VARCHAR(255) | NOT NULL | 用户原始文件名 |
| url | VARCHAR(500) | NOT NULL | 播放访问路径 |
| cover_file_name | VARCHAR(255) | NULL | 封面磁盘文件名 |
| cover_url | VARCHAR(500) | NULL | 封面访问路径 |
| size | BIGINT | NOT NULL, DEFAULT 0 | 文件大小（字节） |
| duration | INT | NOT NULL, DEFAULT 0 | 时长（秒） |
| format | VARCHAR(20) | NULL | 格式：mp4/webm/mkv/mov/avi |
| category | VARCHAR(50) | NOT NULL, DEFAULT '默认' | 分类 |
| tags | VARCHAR(255) | NULL | 标签，逗号分隔 |
| play_count | BIGINT | NOT NULL, DEFAULT 0 | 播放量 |
| like_count | BIGINT | NOT NULL, DEFAULT 0 | 点赞数 |
| owner_id | BIGINT | NOT NULL, FK, DEFAULT 1 | 上传用户 ID |
| uploader | VARCHAR(50) | NOT NULL, DEFAULT 'anonymous' | 上传者显示名快照 |
| status | TINYINT | NOT NULL, DEFAULT 1 | 0 禁用 / 1 正常 |
| create_time | DATETIME | NOT NULL, DEFAULT now | 创建时间 |
| update_time | DATETIME | NOT NULL, 自动更新 | 更新时间 |
| deleted | TINYINT | NOT NULL, DEFAULT 0 | 逻辑删除：0 正常 / 1 删除 |

### 4.3 video_like 点赞记录表

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | BIGINT | PK, AUTO_INCREMENT | 主键 |
| user_id | BIGINT | NOT NULL, FK | 点赞用户 ID |
| video_id | BIGINT | NOT NULL, FK | 视频 ID |
| create_time | DATETIME | NOT NULL, DEFAULT now | 点赞时间 |

## 5. 索引与外键

| 表 | 索引/约束 | 字段 | 用途 |
| --- | --- | --- | --- |
| app_user | UNIQUE `uk_app_user_username` | username | 登录名唯一 |
| app_user | KEY `idx_app_user_status` | status | 用户状态过滤 |
| video | KEY `idx_category` | category | 分类筛选 |
| video | KEY `idx_create_time` | create_time | 最新排序 |
| video | KEY `idx_status_deleted` | (status, deleted) | 列表/检索固定条件 |
| video | KEY `idx_play_count` | play_count | 播放最多排序 |
| video | KEY `idx_owner_id` | owner_id | 归属查询 |
| video | FK `fk_video_owner` | owner_id → app_user.id | 归属用户外键 |
| video_like | UNIQUE `uk_video_like_user_video` | (user_id, video_id) | 点赞去重 |
| video_like | KEY `idx_video_like_video` | video_id | 按视频查询 |
| video_like | FK `fk_video_like_user` / `fk_video_like_video` | user_id / video_id | 外键 |

## 6. 逻辑删除与文件清理

- 删除视频执行 `UPDATE video SET deleted = 1, update_time = NOW() WHERE id = ? AND deleted = 0 AND status = 1`。
- 列表、详情、检索、热门等查询都带 `deleted = 0 AND status = 1` 条件，逻辑删除后数据不再出现。
- 磁盘上的视频文件与封面文件在**事务提交后**清理（注册事务同步回调），避免事务回滚导致文件被误删。
